# 轻笺

轻笺是一款可离线运行的 Windows 桌面便签与待办应用。它使用 Electron 构建，数据保存在本机，不需要浏览器或服务器。

## 直接下载

[下载轻笺 1.7.4（Windows 免安装版）](https://github.com/wojiaoxiaoyueyueya/-/releases/latest/download/%E8%BD%BB%E7%AC%BA.exe)

下载 `轻笺.exe` 后双击即可运行，不需要安装，也不需要另外下载源码或 Node.js。1.7.4 文件 SHA-256：`A572896F13DCE67B4850D07681DDBD0703F76BB6CC62FD27D5064D1B6F951BA0`。

## 功能

- 多便签分类、待办数量、颜色和优先级
- 拖拽排序、搜索与状态筛选、完成进度
- 单次、每天、工作日、每周和每月重复提醒
- 窗口自由缩放、置顶、贴边半隐藏、托盘运行
- 可自由拖动并记忆位置的桌面小部件，可折叠为胶囊并在胶囊内切换便签
- 在小部件中切换事项、快速完成和直接添加待办
- 点击胶囊或展开列表中的事项，可直接编辑详细工作、备注、提醒、数量与优先级
- 可设置关闭后收成小部件、隐藏到托盘或完全退出
- CSS 模糊与高光叠层组成的磨砂玻璃质感
- 透明窗口使用应用自身的圆角玻璃边缘，移除最外沿白框
- 主页面与小胶囊分别设置背景颜色、背景图片、显示方式、多层透明度和文字颜色
- 胶囊外观滑块提供实时浮动预览，停止调整后自动淡出
- 胶囊悬停约 90 毫秒即可展开，交互更跟手
- 设置是可拖出主界面、可跨屏移动、可缩放并能最小化到任务栏的独立窗口，调整主界面时可以直接观察实时效果
- 主窗口、设置窗口与胶囊均贴合真实窗口圆角边沿，不再保留透明黑色外圈
- 深浅主题下拉选项保持清晰可读，全局滚动区使用纤细圆角滚动条
- 背景图片透明度、底色、文字颜色和胶囊外观均按动画帧实时预览，停止操作后再合并保存，减少色板卡顿
- 胶囊自动收起前会核对系统鼠标是否真正离开展开窗口，停留在面板内不会被尺寸变化产生的伪移出事件误收起
- Windows 上优先从 `D:\轻笺data` 读取并保存便签配置与背景图片；没有 D 盘时会使用“文档”中的轻笺数据目录
- 设置页可随时更改默认数据位置，选择后会复制当前数据并在下次启动继续读取；如果目录丢失，启动时可导入备份或在原位置重新建立
- 导入和导出默认打开当前数据目录，但仍可自由选择其他路径
- 主页面与设置窗口均支持八方向拖拽缩放；设置内也可用尺寸滑块及紧凑、标准、宽屏预设调整主页
- 设置选项使用响应式网格排版，在 320 像素窄窗口到最大化状态下都不会横向错位
- 胶囊默认从当前位置向下展开，靠近屏幕底部时自动向上展开，收起后保持原位
- 开机启动、关闭到托盘、提醒声音选项
- JSON 数据导入与导出，删除待办可撤销
- `Ctrl+N` 新建待办、`Ctrl+Shift+N` 新建便签、`Ctrl+F` 搜索、`Ctrl+,` 打开设置

## 本地开发

```powershell
npm install
npm start
```

## 打包

```powershell
npm run build
```

构建结果为 `release/轻笺.exe`。这是唯一的单一融合版，无需安装即可运行，包含全部功能。
